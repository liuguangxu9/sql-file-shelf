# SQL 文件架

一个面向 Microsoft Edge 的本地优先 PWA，用来浏览和编辑用户显式授权目录中的 `.sql`、`.txt` 与 `.md` 文件。

## 核心保证

- 所有文件读写都在浏览器本机完成，不上传文件内容。
- 可保存多个已授权工作区；顶部管理工作区，左侧一体化文件树展示文件夹和文件，右侧以多标签编辑。移除工作区只会删除授权记录，不会删除本地文件。
- 顶部提供快速打开（Ctrl+P）与全文搜索（Ctrl+Shift+F），内容结果显示行号和上下文，点击定位；左侧可筛选文件名或文件夹路径。点击文件夹节点会选中它作为新建目标，树仍显示完整目录层级。
- 导航宽度可拖动并保存在浏览器本地，也可折叠；工作区管理弹层中可拖动重排，文件栏标题里的“排序”菜单可切换文件名、修改时间、格式及升降序。
- 编辑区带同步行号；SQL 文件提供关键字、字符串、注释和数字的轻量语法高亮。
- 编辑区支持真正的 Tab 制表符、多行缩进与 Shift+Tab 反缩进；Alt＋单击可增加光标，按住 Alt 拖动可逐行放置光标，同步输入、粘贴与删除，Escape 返回单光标。
- 新建文件时，名称不含后缀会自动补上 `.sql`；也可明确输入 `.txt` 或 `.md`。
- 选中树中的文件夹后，“新建”和“新目录”就在该节点下创建，节点保持高亮，确认弹窗再次写明目标位置。文件行的“⋯”可重命名或移动文件。移动时先复制并校验，再删除原文件；目标同名时拒绝操作。
- 保存前会检测磁盘文件是否被外部修改；冲突时可比较当前编辑与磁盘版本，再选择取消、重新加载、另存为或覆盖。另存为覆盖已有文件时需确认并备份原文件。
- 保存沿用文件的原编码、BOM 与换行符；若编辑内容无法由原编码表示，工具会阻止覆盖并建议另存为 UTF-8。
- 文件编码以 BOM 和严格 UTF-8 校验优先识别；无 BOM 的遗留编码为概率推断，界面会显示置信度并允许改选。
- 写回前会完成“编码 → 解码 → 文本逐字比较”的无损校验，并创建同目录 `.bak` 备份。

## 开发与构建

```powershell
npm install
npm test
npm run build
npm run serve
```

在 Edge 中打开 `http://localhost:4173` 后，选择工作目录。生产使用应部署 `dist/` 到固定 HTTPS 地址，再从 Edge 的地址栏安装为应用。

GitHub Pages 采用 `gh-pages` 发布分支：`main` 保存源码，`gh-pages` 只保存构建后的静态文件。这样不需要为 GitHub CLI 授予 Actions 工作流权限。

## 文件

- `src/codec.js`：字节级编码识别、转换与保存校验。
- `src/app.js`：工作区授权、跨工作区搜索、文件列表和编辑交互。
- `src/file-model.js`：文件树构建、排序、筛选与时间格式化。
- `tests/codec.test.js`：编码不变与不可表示字符的回归测试。

## 已知边界

无 BOM 的纯 ASCII 或单字节文本可能在多种编码中等价，任何识别器都无法保证唯一正确答案；本工具将其标注为低置信度，而不会把推断当作事实。

## v23 工作台（2026-10-23）

本轮只发布 Cloudflare：[SQL 文件架](https://sql-file-shelf.liugx.top/)。GitHub Pages 保持 v22；默认 Codex 启动映射未更改。源码 main 用于触发 CF 构建，gh-pages 不更新。

- 文件标签保留各自草稿、撤销记录、选区和滚动位置；切换工作区不丢弃其他标签内容。拖动标签调整顺序，Ctrl+Tab 切换标签，Ctrl+Shift+T 重新打开刚关闭的文件（浏览器可能保留部分快捷键）。
- 文件内 Ctrl+F 查找、Ctrl+H 替换，支持大小写、上/下一个、单处/全部替换与撤销。替换使用字面文本，不解释正则或 `$` 占位符。
- 全文搜索包括已打开的未保存草稿；最多展示 100 项，每文件最多 5 处。未授权目录或不可读文件会明确计入跳过数量。
- 最近文件与收藏仅存本地位置引用；失效文件不会静默创建替代文件。已关闭文件重新打开时读取磁盘版本。
- 草稿仅在当前会话保留；浏览器关闭/刷新时会检查所有未保存标签。跨会话草稿恢复属于后续版本。
- 保存期间暂时锁定编辑和切换；保留编码/BOM/换行、备份与外部修改检测。另存目标若已在另一标签打开，需先关闭目标标签。
- 顶部显示授权目录名称；浏览器不提供完整磁盘绝对路径。
